- `templates/github-actions/php-modernization.yml` sets up PHP with `coverage: pcov` instead of `coverage: none`. Without a coverage driver Infection stops before mutating anything, so in a project with Infection installed the template's `infection-diff` result failed in every pull request that changes a source file. The orchestrator steps also set `pipefail`, so a failing gate now fails the job instead of being hidden by `tee`.
