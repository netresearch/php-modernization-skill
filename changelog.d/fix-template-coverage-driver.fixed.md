- `templates/github-actions/php-modernization.yml` sets up PHP with `coverage: pcov` instead of `coverage: none`. Without a coverage driver Infection stops before mutating anything, so in a project with Infection installed the template's `infection-diff` result failed in every pull request that changes a source file. The orchestrator steps also set `pipefail`, so a failing gate now fails the job instead of being hidden by `tee`. The verifier steps set `pipefail` too, and the reporting steps run under `!cancelled()`, so a failing verifier still produces the SARIF upload, the orchestrator run and the PR summary comment; that comment step no longer stops on the verifier's exit 1, which it previously did exactly when there were failures to report. Those steps are skipped after a setup failure, the SARIF upload runs only for a complete SARIF document, and the PR comment is one marked comment of the workflow's own (`github-actions[bot]`) updated on every push and skipped for pull requests from forks.
