- `modernize_loop.py` `infection-diff` (PR mode) no longer gates on an MSI threshold: it zeroes `--min-msi`/`--min-covered-msi`, reads `stats.escapedCount` from Infection's JSON log (`--logger-json`, Infection 0.35.11 or later) and fails on any escaped mutant in the changed lines; a run without a log passes only when Infection reported that the diff holds no source line. The MSI thresholds gate the scheduled full run only.
