- `modernize_loop.py` `infection-diff` (PR mode) no longer gates on an MSI threshold: it zeroes `--min-msi`/`--min-covered-msi`, passes `--with-uncovered`, reads `stats.escapedCount` and `stats.notCoveredCount` from Infection's JSON log (`--logger-json`, Infection 0.35.11 or later) and fails on any escaped or not covered mutant in the changed lines. A run without a log passes only when Infection reported that the diff holds no source line; "No source code from the diff was executed" (no test ran a line of the changed files, as for a new class without a test) fails. The MSI thresholds gate the scheduled full run only. A diff of declarations only fails too; the reference keeps the mutation job out of the required checks so a reviewer can confirm such a diff in writing and merge past the red job.
